Pinterest Assistant — Privacy Policy

Last updated: August 24, 2026

1. What this service is

The Pinterest Assistant is a private assistant for one person. The user sends an image or a link to a personal messaging assistant. The assistant then saves the image as a Pin on the user's own Pinterest boards. Sohail Mohammad operates this service for private use. It is not a public product and it serves one account.

2. Who operates this service

Operator: Sohail Mohammad. Contact: smohammad@together.ai. Questions about this policy or the data it describes go to that address.

3. What information the assistant accesses

The assistant uses the Pinterest API v5 only after the user grants access through Pinterest's own sign-in screen. With that permission, the assistant reads and writes the following on the user's own account:

  • The user's boards (to list them and to save Pins to them).
  • The user's Pins (to create new Pins and to remove Pins the user asks to delete).
  • Basic account information, such as the username.

The assistant does not access other people's accounts. It does not read the user's Pinterest password. Pinterest never shares the password with the assistant.

4. What the assistant stores

  • The access token and refresh token that Pinterest issues after sign-in.
  • The images and links the user sends, and short notes about where to file them.

The service stores this data on a private server with restricted file permissions. It does not store payment data, contacts, or location data.

5. How the assistant uses the information

The assistant uses the information only to do what the user asks: to save a Pin, to list boards, or to remove a Pin. The service does not use the data for advertising. The service does not sell the data.

6. AI processing

To understand a request, the assistant sends the text of the user's message to an AI model provider (Anthropic). This step turns a sentence such as "save this to my fall outfits board" into an action. The assistant does not send the Pinterest tokens or the Pinterest password to the AI provider.

7. How the assistant shares information

The service shares data with two providers, and only as needed to run the service:

  • Pinterest, through the official API, to save and manage the user's Pins.
  • Anthropic, to interpret the user's messages (see section 6).

The service does not share the data with anyone else.

8. Keeping and deleting the data

The service keeps the tokens until the user revokes access. The user can revoke access at any time in Pinterest under Settings → Apps and websites. Revoking access makes the stored tokens stop working. The user can also ask the operator to delete the stored images, links, and tokens by email. The operator deletes them on request.

9. Security

The service sends all requests over encrypted connections (HTTPS). It keeps the tokens in files with restricted permissions on a private server. Only the operator administers that server.

10. Children

This service is not directed at children under 13 and does not knowingly collect their data.

11. Changes to this policy

The operator may update this policy. The date at the top shows the last change.
